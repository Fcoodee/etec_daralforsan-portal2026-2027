# تقرير الأداء — الخلفية (Google Sheets + Apps Script)

> المستودع **عام**: هذا المجلد يحوي كوداً فقط. لا تضع هنا أسماء طلاب ولا رسائل بريد ولا معرّفات ملفات Drive.

## التركيب (مدير النظام، مرة واحدة)
1. أنشئ Google Sheet **خاصاً** في حساب المدرسة. لا تشاركه مع أي معلم.
2. من الشيت: الإضافات ← Apps Script. الصق `Code.gs` و`Index.html`، وفعّل عرض ملف `appsscript.json` من إعدادات المشروع ثم الصق محتواه.
3. شغّل `setup()` ووافق على الصلاحيات.
4. أضف صفوف `Staff` (البريد، الدور: counselor/deputy/principal/admin، المرحلة: primary/middle/secondary/all، active=TRUE).
5. **اختبار الصلاحيات (الخطوة 1):** شغّل `selfTest()` وافتح السجل: يجب أن تظهر كل الأسطر «نجح».
6. **اختبار PDF (الخطوة 2):** أنشئ مجلد Drive خاصاً، وضع معرّفه في Script Properties باسم `PDF_TEST_FOLDER_ID`، ثم شغّل `testPdf()` وافتح الملف الناتج.
7. **نشر تطبيق الويب:** نشر ← نشر جديد ← تطبيق ويب. التنفيذ باسم: أنا. من يصل: **أي شخص في دومين المدرسة**. افتح الرابط من حساب موظف ونفّذ «اختبر حسابي».

## ما يُنظر في نتيجة الاختبارين
| الاختبار | المطلوب |
|---|---|
| `selfTest` | كل السطور «نجح» (عزل المراحل، رفض المعطّل، حد النقاط، القفل بعد التسليم، منع الاعتماد) |
| `testPdf` | العربي متصل وبالاتجاه الصحيح، والجدول سليم، والصفحة واحدة |
| تطبيق الويب | يظهر دورك ومرحلتك وعدد طلابك الصحيح |

إن فشل `testPdf` في الخط أو الاتجاه فالمسار البديل: قالب Google Docs، أو توليد PDF بمتصفح بلا واجهة (انظر `HANDOFF.md`).
